# 事件级编辑功能 - 需求与实施文档

## 需求

用户在阿瓦隆对局记录过程中，经常会记错某条记录（比如任务1的失败牌数、某轮投票结果、某次提案人选）。
之前只能通过"回滚整个任务"删除后续所有记录重打，代价太大。

目标：**点时间线里的任意一条记录，直接弹出对应的编辑窗口修改，保存后自动撤回旧事件、追加新事件，下游状态自动重算。**

## 支持的事件类型

| 事件类型 | 点击后打开的弹窗 | 编辑内容 |
|---|---|---|
| TEAM_PROPOSED（组队提案） | ProposalSheet | 队长、队员名单 |
| TEAM_VOTE_RECORDED（组队投票） | VoteSheet | 每票赞成/反对/未知 |
| MISSION_RESOLVED（任务结果） | MissionSheet | 失败牌数、观察结果 |

其他事件（任务开始、提案决议、刺杀等）暂不支持编辑。

## 交互

1. 时间线每条记录卡片可点击（无删除按钮，点击即编辑）
2. 点击后打开对应编辑弹窗，加载当前已记录的值
3. 修改后点保存：
   - 撤回该类型同任务/同提案的旧事件（标记 retracted=1）
   - 追加新事件
   - reducer 自动重算所有下游状态（胜场数、任务进度、终局判定）
4. 取消则不改动任何数据

## 不做的事

- 不做"只删单条不影响其他"的细粒度冲突检测——撤回旧事件追加新事件后，reducer 自动重算，天然处理依赖
- 不做编辑历史/撤销编辑——撤回就是软删除，可通过再编辑改回来

## 实施

### 改动文件

1. **RecordTimelineSection.kt**
   - TimelineRow 加 clickable
   - RecordTimelineSection 加 onEntryClick 回调

2. **RecordScreen.kt**
   - onEntryClick 根据 eventType 路由到对应 Sheet

3. **RecordViewModel.kt**
   - saveMission：编辑模式下撤回同 questNo 的旧 MissionResolved
   - saveVotes：编辑模式下撤回同 questNo+proposalNo 的旧 TeamVoteRecorded
   - confirmProposal：编辑模式下撤回同 questNo+proposalNo 的旧 TeamProposed

4. **RecordUiState.kt**
   - SelectLeader action 接受 Int?（支持取消队长）

### 撤回机制

复用已有的 `repository.retractEvent(matchId, eventId)`，事件标记 retracted=1，replay 时自动跳过。
不需要改数据库 schema。

## 验收

- [x] 点时间线任务结果，弹出 MissionSheet 可改失败牌数，保存后胜场数更新
- [x] 点时间线投票记录，弹出 VoteSheet 可改票，保存后决议重算
- [x] 点时间线提案记录，弹出 ProposalSheet 可改队长/队员，保存后更新
- [x] 旧事件被撤回不显示在时间线
- [x] 下游状态（进度条、终局）自动重算
