### P0：信息架构
1. **UX-01 主 Tab 无效入口**：RECORDS Tab 只显示空态引导回首页，REVIEW Tab 引导回 RECORDS，形成"空页面→回首页"循环

### P1：关键路径
5. **UX-05 首页焦点卡**：当前首页只有列表，没有"继续上一局"焦点区域

## 统一设计系统

### 颜色（已有 Token，不新增）
- 主色：硅粉 `#AD4D68`（浅色）/ `#E89BB0`（深色）
- 背景：`#F8F7F8`（浅色）/ `#121114`（深色）
- 卡片：`#FFFFFF`（浅色）/ `#1A181C`（深色）
- 成功：`#17795F` / 失败：`#C8483C`
- 强调：`#3F6E8C`（梅林/派西维尔）

### 间距（Dimens.kt 已有）
- xs: 4dp / sm: 8dp / md: 16dp / lg: 24dp / xl: 32dp

### 圆角（Shape.kt 已有）
- small: 8dp / medium: 12dp / large: 16dp

### 动效
- 时长：短 150ms / 中 300ms / 长 500ms
- 曲线：Spring 物理插值（Material Motion）
- 共享元素转场：列表→详情

### 组件规范
- 所有可点击元素 ≥ 48dp
- 座位格 ≥ 56dp（已有）
- BottomSheet 操作按钮：主按钮右对齐，取消按钮左对齐
